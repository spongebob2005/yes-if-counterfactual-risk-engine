Demo limitation: the scores are not trained, calibrated, or validated. This page does not access payment data, call PayPal, or make payment decisions.

Run the project

Start the interactive dashboard on your computer. Python 3.10 or newer is required.

python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
streamlit run dashboard/app.py

On Windows, activate with .venv\Scripts\activate. Streamlit prints the local URL.

PayPal sandbox checkout

The separate checkout service demonstrates a fixed $1 sandbox purchase. It requires PayPal Developer sandbox credentials and does not use the risk score.

cp .env.example .env
# Add Sandbox Client ID and Secret to .env
python -m pip install -r requirements.txt
uvicorn src.paypal.checkout_app:app \
  --host 127.0.0.1 --port 8000

Open http://localhost:8000/ and approve with a sandbox buyer account. This public page never asks for credentials.
